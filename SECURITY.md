# Security Policy / Política de Segurança

## English

### Supported Versions

`transactional-outbox-lab` is currently in development version `0.1.0`.

| Version | Supported |
|---|---|
| `0.1.x` | Yes |

### Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues.

Report vulnerabilities privately through GitHub Private Vulnerability Reporting at:

- <https://github.com/martinlofranodeoliveira/transactional-outbox-lab/security/advisories/new>

For general institutional contact, visit the official Lofrano Tecnologia homepage:

- <https://lofranotecnologia.com.br>

## Português

### Versões Suportadas

`transactional-outbox-lab` encontra-se atualmente na versão de desenvolvimento `0.1.0`.

| Versão | Suportada |

### Como Reportar uma Vulnerabilidade

Por favor, **não** reporte vulnerabilidades de segurança em issues públicas do GitHub.

Utilize o canal privado de relatos de vulnerabilidade do GitHub (*GitHub Private Vulnerability Reporting*) em:

- <https://github.com/martinlofranodeoliveira/transactional-outbox-lab/security/advisories/new>

Para contato institucional geral, acesse o site oficial da Lofrano Tecnologia:

- <https://lofranotecnologia.com.br>
